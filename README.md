## Tujuan
Mengolah kumpulan data numerik menggunakan list Python,
meliputi pengaksesan elemen, manipulasi list, perhitungan
statistik, penyaringan nilai, dan penggunaan fungsi.

## Struktur Program
Folder latihan berisi enam program:
1. 01_buat_list.py: Membuat list dan menghitung jumlah data.
2. 02_indeks_slicing.py: Mengakses elemen dengan indeks dan slicing.
3. 03_manipulasi_list.py: Mengubah, menambah, dan menghapus data.
4. 04_agregasi_nilai.py: Menghitung statistik nilai.
5. 05_filter_kelulusan.py: Menyeleksi nilai yang lulus.

Folder praktik berisi:
- analisis_nilai_mahasiswa.py: Menganalisis statistik dan kelulusan.

Folder latihan juga berisi 06_fungsi_statistik.py
untuk menghitung rata-rata menggunakan fungsi.

## Cara Menjalankan
Jalankan perintah berikut dari folder utama repositori:

python latihan/01_buat_list.py
python latihan/02_indeks_slicing.py
python latihan/03_manipulasi_list.py
python latihan/04_agregasi_nilai.py
python latihan/05_filter_kelulusan.py
python latihan/06_fungsi_statistik.py
python praktik/analisis_nilai_mahasiswa.py
